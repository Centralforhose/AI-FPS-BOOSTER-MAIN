## `> OVERVIEW`

**Wardogs FPS Booster V3.5** is a collection of system optimization tips and settings for players who want better responsiveness and stability in Windows while gaming — **without sacrificing graphics quality**.

The project focuses on careful optimization: reducing unnecessary background load, preparing a cleaner gaming session, and avoiding questionable “magic tweaks.”

> **Core principle:** Improve performance without intentionally lowering the game's resolution, texture quality, shadows, or other visual settings.

## `> CORE FEATURES`

- ⚡ **Performance-focused** — tips and settings aimed at reducing unnecessary background activity.
- 🎯 **Visuals preserved** — no mandatory reduction of in-game graphics settings.
- 🧠 **Stability first** — prioritizes predictable system behavior and reliability.
- 🛠️ **User-controlled** — changes should be understandable and reversible whenever possible.
- 🖥️ **Windows gaming** — focuses on preparing Windows for a gaming session.

## `> WHAT IT DOES`

| Module | Purpose |

| `SYSTEM CLEANUP` | Helps identify unnecessary apps and background tasks before gaming. |
| `GAMING SESSION` | Provides guidance for preparing the system before launching a game. |
| `VISUAL LOCK` | Keeps your preferred in-game graphics settings intact. |
| `SAFE TWEAKS` | Emphasizes changes that can be checked and rolled back. |

*Actual results depend on your PC configuration, drivers, the game, and background processes. FPS gains are not guaranteed.*

## `> QUICK START`

1. **Prepare your system.** Install current Windows updates and graphics drivers from official sources.
2. **Create a restore point.** This gives you a recovery option if a system change causes problems.
3. **Close unnecessary apps.** Do not disable system services at random.
4. **Apply only understood settings.** Read what each change does before using it.
5. **Compare results.** Test FPS and smoothness in the same in-game scene before and after optimization.

## `> RECOMMENDED CHECKLIST`

- [ ] Check CPU and GPU temperatures under load.
- [ ] Make sure the game is using the intended graphics card.
- [ ] Update drivers from official sources.
- [ ] Disable startup apps only if they are unnecessary.
- [ ] Check available disk space.
- [ ] Compare FPS and frame times before and after optimization.
- [ ] Confirm that resolution and graphics quality have not changed.

## `> SAFETY PROTOCOL`

```text
[01] BACKUP FIRST
[02] CHANGE ONE SETTING AT A TIME
[03] TEST AFTER EVERY CHANGE
[04] KEEP A ROLLBACK PATH
[05] NEVER DISABLE SECURITY OR CORE SYSTEM SERVICES BLINDLY
```

- Do not disable antivirus protection, Windows Security, or essential system services for questionable performance gains.
- Do not run unknown `.reg`, `.bat`, or `.ps1` files without checking their contents.
- Do not expect identical results across all PC configurations.
- If a tweak reduces stability, restore the original setting.

## `> FAQ`

**Will graphics quality be reduced?**

No intentional reduction in visual quality is intended. After applying any game-related settings, check that resolution, textures, and other graphics options remain unchanged.

**Will I get more FPS?**

The results depend on the performance bottleneck: CPU, GPU, memory, temperatures, or background tasks. A specific FPS increase cannot be guaranteed.

**Will it work on every PC?**

The general Windows recommendations can apply to many systems, but results depend on your hardware and current configuration.
